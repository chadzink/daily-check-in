# Workflow 07: Sprint Retrospective & Continuous Improvement

- **Scrum Ceremony:** Sprint Retrospective
- **Participants:** Full Squad & User
- **Trigger:** Milestone completion (Milestones 1 through 6)
- **Primary Output:** Updated `GEMINI.md`, agent instructions, and skill runbooks

---

## Process Flow
1. **Analyze Metrics & Friction:**
   - Test execution times, flakiness, and emulator restarts.
   - Ambiguities encountered during story scoping or developer handoffs.
2. **Determine Actionable Changes:**
   - Update project architectural rules or standards in `GEMINI.md`.
   - Tune agent definition prompts in `.agents/agents/`.
   - Update skills in `.agents/skills/` with automated checks.
