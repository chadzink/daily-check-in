# Workflow 06: Sprint Review & Sign-Off

- **Scrum Ceremony:** Sprint Review & Demo
- **Participants:** `@product-owner`, `@tester`, User (Product Sponsor)
- **Primary Input:** Approved QA Report & Demo Evidence
- **Primary Output:** Final Definition of Done (DoD) Sign-Off & merge approval

---

## Process Flow
1. **QA Evidence Audit:** Confirm all scenarios in `/plans/PLAN-*.md` passed with documented proof in `test-reports/`.
2. **Definition of Done (DoD) Verification:**
   - Architecture & code hygiene standards met.
   - Design tokens and WCAG AA contrast satisfied.
   - Production single-binary packaging builds cleanly.
3. **User Demo Presentation:** Present user journey walkthrough with visual evidence.
4. **Approval Gate:** Obtain human-in-the-loop approval before merging to `main`.
