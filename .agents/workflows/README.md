# DailyCheckIn - Scrum Workflows

For the comprehensive end-to-end guide, see [`docs/WORKFLOWS.md`](../../docs/WORKFLOWS.md).

   - Gate: Rapid Escalation & Unblocking

   - Lead: `@tester` | Collaborator: `@developer`

6. [06 - Sprint Review & Sign-Off](./06-sprint-review.md)

7. [07 - Sprint Retrospective & Continuous Improvement](./07-retrospective.md)
   - Participants: Full Squad & User
